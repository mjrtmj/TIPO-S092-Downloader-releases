# TIPO 審查歷程下載器（S092）— 發佈頁

貼上多筆台灣專利案號，批次下載每一案在智慧財產局的**完整審查歷程公文 PDF**
（申請書、審查意見通知、申復、審定書……收文與發文全卷），並可選擇合併為
單一帶書籤的整卷 PDF。資料來源為智慧局官方「專利公開資訊 API（S092）」。

**本 repo 只提供安裝檔下載與使用說明**，不含程式原始碼。

> 本軟體為免費軟體、非官方工具，與經濟部智慧財產局（TIPO）無任何隸屬、
> 贊助或背書關係。

## 下載

到 **[Releases](../../releases/latest)** 頁面下載最新版
`TIPO-S092-Downloader_vX.Y.Z_setup.exe`，雙擊安裝即可
（安裝後程式名稱顯示為「TIPO審查歷程下載器」；GitHub 附件
不支援中文檔名，故下載檔名為英文）。

- 支援 Windows 10 / 11，不需系統管理員權限（安裝到使用者資料夾）。
- 若出現藍色「Windows 已保護您的電腦」畫面：點「其他資訊」→「仍要執行」。
  這是 Windows 對未購買數位簽章之新程式的預設警告，非病毒偵測；
  每個 Release 頁面均附安裝檔 SHA-256 供自行核對。
- 升級直接執行新版安裝檔覆蓋安裝即可，帳密設定會保留。

## 使用前準備：申請 S092 API 帳號（免費）

本程式需要智慧局「專利公開資訊 API」帳號（與 e 網通登入帳密**不是同一組**）：

1. 註冊「智慧財產局 e 網通」帳號（自然人即可，免費）。
2. 進入智慧局「專利公開資訊查詢」網頁，點右上角「申請專利公開資訊 API」。
3. 以 e 網通帳號登入送出申請，審核通過後 API 帳號密碼會寄到 email。
4. 首次啟動程式會跳出「設定」視窗，填入該組帳密、按「測試連線」後儲存。

帳密只存在本機安裝資料夾內的 `config.json`，程式不會上傳到任何地方。
請每人申請自己的帳號——配額逐帳號計算，多人共用容易觸發流量限制。

## 主要功能

- **三種案號混貼**：申請案號（104142817）、公開號（201637458）、
  公告號（I642307／M…／D…）每行一筆混貼皆可，自動轉換並去重。
- **文件勾選**：依收文／發文類別與關鍵字（審查意見、核駁、申復…）快篩；
  「只勾新增」一鍵只勾尚未下載的文件，適合增量追 OA 進度。
- **關聯案展開**：一鍵把分割／改請的母案、子案整條家族抓進清單一併下載。
- **穩健下載**：逐案序列下載、單案失敗不中斷批次；可暫停／停止；
  重跑自動跳過已完成檔案（續傳）；遇 API 限流自動暫停保留進度。
- **整卷合併**：可另產出單一 PDF，兩層書籤（公文→檔案），照時間排序。
- 每案輸出 `case_info.json`（書目與文件清單快照）與
  `download_log.jsonl`（下載稽核紀錄）。

詳細操作見 [使用說明.md](使用說明.md)（安裝後也可從開始功能表開啟）。

## 已知限制（官方 API 範圍，非程式問題)

- 僅涵蓋**約民國 97 年（2008）以後申請**的案件；申請未滿 18 個月尚未
  公開的案件同樣查不到。
- 不含舉發卷宗文件。
- 一案兩請的另一案、衍生設計與母案之間，官方 API 無關聯資料，
  需自行分別輸入案號。
- 官方未公布流量配額，程式保守以每次呼叫間隔 1 秒下載（一案 20 件約半分鐘）。
